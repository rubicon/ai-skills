# Codebase Memory

Query a codebase knowledge graph (via a `codebase-memory` MCP server) instead of grep — finding
definitions, callers, impact radius, architecture, and hot paths, with tiered evidence standards
for how much verification a claim needs. See [SKILL.md](SKILL.md) for the full tool reference,
workflows, and gotchas.

## Install

```bash
skillshare install github.com/rubicon/ai-skills -s codebase-memory
```
