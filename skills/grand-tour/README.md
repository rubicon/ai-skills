# Grand Tour

An onboarding tour of a codebase: what it is, its main parts, one real flow traced through the code, the conventions a newcomer would trip over, and where to start. Uses a code-graph index when one exists. See [SKILL.md](SKILL.md) for the shape and trigger conditions.

## Install

```bash
skillshare install github.com/rubicon/ai-skills -s grand-tour
```
