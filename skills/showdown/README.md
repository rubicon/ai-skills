# Showdown

Put two or three genuinely different approaches head to head on the same terms, pick one, and stop before planning or code. For when you know what you want but not how to approach it. See [SKILL.md](SKILL.md) for the output shape and trigger conditions.

## Install

```bash
skillshare install github.com/rubicon/ai-skills -s showdown
```
