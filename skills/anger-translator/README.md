# Anger Translator

Turn a heated draft into a message you can send at work: the same grievance, ask, and seriousness, with nothing in it that could get you disciplined or fired. It reads the intensity and audience, keeps the facts and any consequence you stated, removes the heat, and tells you what it cut and where the political risk is. See [SKILL.md](SKILL.md) for the rules and output shape.

## Install

```bash
skillshare install github.com/rubicon/ai-skills -s anger-translator
```
