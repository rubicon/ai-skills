# Goalpost

Turn what you want into one Claude Code `/goal` line that a long unattended run can finish: an observable outcome, evidence the goal evaluator can see in the conversation, constraints, and an escape clause so an impossible goal stops instead of looping. See [SKILL.md](SKILL.md) for the shape and trigger conditions.

## Install

```bash
skillshare install github.com/rubicon/ai-skills -s goalpost
```
