# Resume and Profile Alignment

The résumé and the profile are read by different people for different reasons, and a contradiction
between them is a live liability — search firms and internal recruiters routinely hold both open on
one screen.

## What must be identical

Non-negotiable. Any divergence here is a finding, not a style choice:

- Employer names
- Job titles
- Date ranges, to the month
- Anything numeric that appears in both
- Education, credentials, certifications

A date that differs by three months looks like carelessness at best. It is also the most common
finding in a first audit, because profiles are updated at role changes and résumés are updated at
job searches, and the two drift.

## What should differ deliberately

| Dimension | Résumé | Profile |
|---|---|---|
| Length | 1–2 pages, ruthlessly cut | Room to argue |
| Voice | Implied first person, no pronouns | Explicit first person |
| Tone | Formal | Direct but human |
| Keywords | Tuned to one posting | Broad across the target category |
| Audience | One employer | Recruiters, boards, clients, peers, future colleagues |
| Personality | Minimal | Present and deliberate |
| CTA | None | One, specific |
| Currency | Updated per application | Always current |

## What the profile can do that the résumé cannot

- **Carry a point of view.** A résumé asserts competence; a profile can demonstrate judgment.
- **Show the work** through Featured — artifacts a résumé can only name.
- **Speak to more than one audience.** A résumé targets a role. A profile can serve an executive
  search and an advisory pipeline simultaneously, if the conflict is resolved explicitly rather
  than blurred.
- **Be corroborated** by recommendations and visible activity.

## What the résumé can do that the profile cannot

- **Target one posting precisely.** Never rewrite the profile for a single job — that is
  `salience-career`'s alignment workflow, and it changes the résumé, not the public profile.
- **Include information the user does not want public** — compensation history, references,
  full address, or an in-progress search.

## Consistency audit

When both are available:

1. Build a table of every role: title, employer, start, end, from each source.
2. Flag every mismatch. Do not resolve by preference; ask.
3. Compare metrics claimed in both. A number that differs is a serious finding — one of the two is
   wrong, and both are in circulation.
4. Check for roles present in one and absent from the other. Omission is legitimate (short tenures,
   unrelated early work) but should be deliberate and consistent.
5. Check scope claims. A résumé saying "team of 12" and a profile saying "led 20+" is the kind of
   drift that surfaces in a reference call.

```
[VERIFY]
Résumé and profile disagree on 3 facts:

  Head of Marketing, start date
    Résumé  March 2021  ·  Profile  June 2021

  Hollis team size
    Résumé  22  ·  Profile  "25+"

  CAC improvement
    Résumé  38%  ·  Profile  "nearly 40%"

The first is a factual conflict. The second and third are the profile rounding upward — small,
and exactly the pattern a diligence check looks for. Recommend the profile matches the résumé
in all three.
```

## Direction of correction

Default to **correcting toward the more conservative, sourced version.** Where the résumé is
sourced from documentation and the profile is from memory, the résumé wins. Where the user
confirms the profile is right and the résumé is stale, update the ledger and flag that the résumé
now needs the same fix — a correction that fixes one surface and leaves the other is half a fix.
